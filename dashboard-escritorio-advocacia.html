Sobre o encontro

Instalação e primeiros passos no Claude Code 💻

O Guilherme apresentou o Claude Code pro time e todos instalaram ao vivo, direto no terminal. O objetivo não foi resolver tudo hoje — foi destravar a ferramenta e deixar cada um pronto pra começar a testar.

A ideia central
🧞

O Claude Code é um “gênio” à sua disposição —
você só precisa saber conversar com ele.

Regra de ouro: travou? Tira um print, copia e manda pro Claude. Ele te guia no resto.
O que aprenderam hoje
⚙️

Instalar e abrir o Claude Code

Todo mundo instalou no terminal. Pra reabrir depois: abrir o terminal e escrever “claude”. A primeira vez é a mais chatinha — depois vira um chat.

🧑‍🏫

Duas peças: tutor e ferramenta

O Claude (app/chat) é o tutor — pra tirar dúvida. O Claude Code é a ferramenta que faz o trabalho de verdade, com acesso ao computador.

📩

Conectar o Gmail (MCP)

Dá pra ligar o e-mail ao Claude pra ele ler e classificar. Ele mesmo conduz o passo a passo.

🚫

Sem ferramentas externas

Não precisa montar automação no N8N. É só conversar com o Claude Code que ele resolve — de fatura a organizar pastas e até criar um app.

O que o escritório precisa
📥

Triagem automática de e-mails

Classificar os e-mails do grupo jurídico por urgência, risco e SLA — hoje é tudo manual.

⚖️

Distribuir demandas pro advogado certo

Cada e-mail vira uma demanda e cai no Google Workspace já marcando o advogado responsável.

⏱️

Desafogar o administrativo

A equipe já enxugou com IA na produção. Agora o gargalo é a parte administrativa tomando tempo do time.
